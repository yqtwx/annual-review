# 来源清点、分页与证据

## 宿主适配

先检查工具清单、宿主配置和用户提供的导出目录，选择实际存在的接口。不存在的工具名或存储格式不得假设可用。

| 来源 | 应读取 | 不能据此推断 |
| --- | --- | --- |
| Codex 桌面 | `list_projects` 项目清单；`list_threads` 当前聊天；`list_archived_threads` 每页归档；`read_thread` 按游标读取年度相关历史；`list_artifacts` 当前聊天附件 | 最近列表就是全年全集；聊天摘要就是完整消息；提到的 PR 都是已交付成果 |
| 其他 agent（例如 WorkBuddy、Claude Code） | 宿主提供的会话接口、经配置确认的本地日志或用户导出；先检查少量记录确定 schema，再只读解析 | 所有工具都采用同一日志目录；文件修改时间等于活动时间；文件名包含年份就只含该年 |
| ChatGPT / 导出记录 | 可用连接器、官方导出或用户提供的 JSON/HTML；区分分支、重试、角色和真实时间戳 | 有安装技能就能读取其他账号、平台或设备；标题包含完整对话 |
| 项目目录 / Git | 已发现的项目清单、年度提交、交付文件、发布与验证记录；按仓库/稳定项目 ID 聚合 | 提交数衡量价值；仓库提交者都属于用户；现在的文件状态就是当年的状态 |

使用 Codex 桌面时注意：`list_threads` 返回有限的最近项，可能没有全量分页。`list_archived_threads` 归档必须循环 `nextCursor`，Codex 与 ChatGPT 是不同来源；`read_thread` 可能只暴露回合摘要或截断内容。记录这些接口的真实限制。若支持本地记录或官方导出，用其补齐；否则标注部分可见，绝不假装正文已读。只有当前宿主的工具 schema 明确支持时才传对应参数。

文件采集优先使用明确的日志根目录或项目列表，不递归扫描整个磁盘，不读取凭据文件。工具受限时先完成可见范围，不反复索要已经给出的权限。若用户要求全量、但存在必须补充的数据来源，在明确说明缺口后询问如何补齐；已有部分可先生成标注范围的报告。

## 遍历与断点

为每个来源保存 `source_id / cursor / enumerated / read / failed / oldest / newest / body_level / complete`。按稳定 ID 记录已读项目、会话、消息与分支。相同内容出现在本地与云端时，以来源 ID 和消息 ID 优先去重；缺少 ID 时采用时间、角色、规范化正文的哈希，保留合并依据。正文相同但日期不同的重复提问不能自动合并。

跨年会话仅统计本年度消息和事件；项目只要年度有相关活动即可纳入，并保留项目开始时间是否早于年度。进行中的会话不因更新时间在下一年就被整体排除。使用本地时区转换时间后过滤；时区缺失的记录保留为未知时间，不计入小时分布或精确活跃日。

每批建议先保存记录索引，再产出带证据 ID 的项目事实、主题与代表片段。跨批汇总从事件索引计算统计，不把各批摘要里的数字相加，避免重复计数。上下文不足时读断点与项目卡继续，不重复采集也不凭记忆恢复数字。

## 指标口径

- 项目数：稳定项目实体的去重数；一个项目的多个聊天只算一个项目。无法映射的会话独立列出。
- 会话数：来源命名空间下稳定会话 ID 的去重数；分支是否另计必须明确。
- 用户消息数：人类用户提交的消息；排除系统、工具、agent 自动续跑与跨 agent 转发。
- 活跃日：用户主动发送消息或可归属用户的项目事件发生的本地日期并集；不以 agent 自动活动膨胀统计。
- 月度分布：明确是消息量、活动日还是成果数；缺失月份为「未覆盖」，未来月份不显示为零。
- 完成 / 发布项目数：需要交付或发布证据；只有计划或讨论就标「探索中」或「状态未验证」。
- 高频主题：从实际对话语义归纳，排除模板、粘贴代码和工具输出；按独立会话覆盖度加原文实例解释，不假装词频等于兴趣。

同比只在两年覆盖范围与口径可比时使用。时间密集峰值可描述「记录最集中的一天」，不可推导「工作最努力」。

## 证据记录

`evidence.jsonl` 一行一个对象：

```json
{"id":"e-001","source_id":"host:session-id","locator":"message-id 或文件行/官方链接","timestamp":"2026-04-18T15:20:00+08:00","role":"user","excerpt":"必要的脱敏短摘录","supports":["chapter-03","metric-projects"],"confidence":"direct"}
```

不保存访问 token 或原始完整日志。不能使用会泄露绝对私密路径的外部链接。单个事实关联多个证据时保留全部定位。矛盾记录注明发生先后，不能只挑支持正向故事的部分。

`coverage.md` 列出指定时区、年度区间、采集时刻、来源、读取数、遗漏与失败、正文级别、去重方式、状态证明和指标定义。区分「穷尽可访问接口返回」与「确定覆盖全部历史」，只有来源可证明全集且已完成遍历时才声明全量。
